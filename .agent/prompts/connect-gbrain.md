# Подключение разработчика к общей памяти

Передать этот промпт локальному Codex. Личный credential владелец выдаёт отдельно
по защищённому каналу; его содержимое не вставлять в промпт.

```text
Обнови текущий checkout из main и подключи Codex к GBrain проекта.

Репозиторий: https://github.com/benzocloud/hack-rnd-autumn-2026
MCP URL: https://gbrain.brokebyte.me/mcp
Entity проекта: hack-rnd-autumn-2026

1. Прочитай существующий AGENTS.md. Проверь remote, текущую ветку и git status.
   Получи актуальный main из подтверждённого remote этого репозитория.
   Если текущая ветка main и рабочее дерево чистое, обнови её через fast-forward.
   Если работаешь в другой чистой ветке, влей полученный main в текущую ветку.
   При незавершённых изменениях или конфликтах останови обновление и сообщи
   причину. Не используй reset --hard, force, автоматический stash или смену
   ветки с незавершённой работой. Не пушь изменения.
2. Прочитай обновлённые AGENTS.md и .agent/infra/gbrain/README.md.
   Проверь наличие setup-local.py и Python 3.11+.
3. Уточни у меня путь к файлу с моим личным developer credential GBrain.
   Не проси содержимое токена в чат, не выводи его и не добавляй в Git.
4. Выполни из корня репозитория с Python 3.11+:
   python3 .agent/infra/gbrain/setup-local.py --token-file <путь>
   Если GBrain уже настроен, проверь подключение без перезаписи конфигурации.
   Сохрани остальные MCP-интеграции. Не копируй конфигурацию другого разработчика:
   setup создаёт абсолютные пути именно для текущего checkout.
5. Проверь, что .codex/config.toml и .agent/local/ игнорируются Git.
6. Если нужна новая сессия Codex в доверенном проекте, сообщи об этом.
   В новой сессии выполни реальный GBrain recall для entity
   hack-rnd-autumn-2026 и запроса об адресе общей памяти.
   Сообщи результат проверки без секретов; не выдавай отсутствие инструмента
   в текущей сессии за проверенное успешное подключение.

Далее вызывай recall по теме задачи перед планированием и разработкой.
Сверяй память с кодом, Git и ADR. Записывай только проверенные сведения с
источником и датой, без секретов. При недоступности GBrain сообщи причину и
продолжай по репозиторию. Не устанавливай локальный сервер GBrain и не меняй
удалённую инфраструктуру. Если setup отсутствует после обновления, сообщи об этом.
```
