# Re-review after new commits

Run only after a new `/agent-review` PR comment; a push alone is not authorization to start another review (ADR-011). Read the current PR head SHA and compare it to the previously reviewed SHA. Re-read project instructions, accepted ADRs, Issue criteria and available GBrain context. If memory is disabled/unavailable, disclose that and continue (ADR-010). Verify whether earlier findings are resolved; review new/changed lines and interactions; do not carry forward a passing result from an older SHA. Re-evaluate the current PR title and changed files under ADR-012 before invoking skills: literal `INFRA/ML:` requires Go skills, standalone `ML:` excludes them. Run required installed review skills again as configured. Avoid duplicate comments. Output updated findings and a current-SHA review summary. Before publication recheck head SHA; discard stale output. No code edits, merges or deployments.
