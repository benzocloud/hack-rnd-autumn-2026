# Re-review after new commits

Read the current PR head SHA and compare it to the previously reviewed SHA. Re-read project instructions, accepted ADRs, Issue criteria and relevant GBrain context. Verify whether earlier findings are resolved; review new/changed lines and interactions; do not carry forward a passing result from an older SHA. Run required installed review skills again as configured. Avoid duplicate comments. Output updated findings and a current-SHA review summary. No code edits, merges or deployments.
