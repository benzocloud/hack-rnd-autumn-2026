# Контекст больших планов для /question

Цель: позволить задать вопрос по читаемому плану, когда его размер превышен
только из-за закодированного служебного состояния.

Текущее состояние: тестовый план из одного этапа занимает 35 989 символов;
обработчик вопросов отклоняет файлы длиннее 24 000 символов. Читаемый текст
и повторяющее его служебное состояние сейчас передаются вместе.

## Этап 1 — подготовка контекста управляемого плана

Статус: Принят. Реализация и локальные проверки завершены; разработчик
одобрил результат и публикацию командой «апрув пуш».

Результат: вопрос получает весь читаемый текст плана и явное уведомление
об исключении закодированного состояния; исходный файл сохраняется.

Файлы: `.agent/infra/conversation/ssh_conversation.py`,
`.agent/infra/conversation/github_conversation.py`,
`.agent/infra/tests/test_conversation.py`, `.agent/infra/README.md`.

Зависимости: установленный формат планов и текущий протокол вопросов.

Предлагаемые действия:
- [x] Исключать только известное служебное состояние управляемого плана после
  проверки его соответствия видимому тексту.
- [x] Сохранить исходные номера строк читаемого текста и уведомить модель и автора
  вопроса о непереданном состоянии.
- [x] Сохранить лимиты для читаемого текста и общего контекста, запрет инструментов,
  модель, права и формат ответа.

Предлагаемые проверки: воспроизведение отказа на большом корректном плане;
прохождение вопроса после сокращения; неизменность исходника; отказ для
повреждённого состояния, слишком большого читаемого текста и обычных файлов;
полный набор инфраструктурных тестов, Ruff и проверка пробелов.

Критерий завершения: весь читаемый план передан без скрытого сокращения,
ограничения и права сохранены, проверки пройдены. Затем остановка для ревью
и явного апрува разработчика.

Результат локальных проверок:
- До исправления воспроизведён отказ корректного большого плана и отсутствие
  защиты от скрытия повреждённого состояния.
- На сохранённом плане тестового PR #9 размер источника для вопроса уменьшился
  с 35 989 до 7 965 символов. Весь читаемый текст и его строки сохранены;
  исходный файл не изменён.
- После ревью воспроизведён и исправлен повторный выбор плана по ссылкам
  с `./` и `/./`: пути нормализуются до удаления дубликатов и определения
  управляемого плана. Регрессия проверяет единственный источник без
  закодированного состояния и неизменность исходного файла.
- Пройдены все 90 инфраструктурных тестов, Ruff и проверка пробелов.
  Проверки модели, GitHub и SSH заменены заглушками; реальные обращения
  к модели и серверу не выполнялись.
- Сохранена прежняя структура ответа. Перед установкой нужно согласованно
  обновить обработчики вопроса и публикации; живые проверки ещё не выполнены.

Вне скоупа: увеличение лимитов, автоматический переход на другую модель,
изменение планов или статусов этапов, проверка ссылок, ADR-021, публикация
и установка на runner. GBrain недоступен; для исправления не требуется.
