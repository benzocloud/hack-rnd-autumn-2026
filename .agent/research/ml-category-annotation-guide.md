# Инструкция независимым разметчикам операций

Дата: 2026-10-24. Работать по отдельным `blind_A.csv` и `blind_B.csv` в локальном
`services/ml/artifacts/balance_v1_verified/human_audit/`. Не открывать
`coordinator_only/rule_key.csv` до сдачи обоих ответов. Это ключ текущих правил,
не правильные ответы. Исходные назначения и выборка не публикуются.

## Как размечать

Каждый человек независимо заполняет `human_category`, `reason`, `alternative`,
`uncertain`. Прочитать направление, назначение и контрагента целиком. Не подгонять
ответ под прогноз. Если нужной категории нет, написать `other_proposed` и
предложить её смысл. Если информации недостаточно, выбрать `unknown` и описать,
какого контекста не хватает. Не выводить категорию только из имени банка/ИНН.

После двух независимых ответов координатор считает согласие и матрицу разногласий
по стратам. Затем человек-арбитр сохраняет итог и причину, не стирая первые ответы.
До этого нет измеренной точности или человеческого подтверждения категорий.

## Значения меток

| Метка | Смысл |
| --- | --- |
| acquiring_revenue | Зачисление карточной выручки, эквайринга, СБП |
| cash_revenue | Внесение/инкассация наличной выручки |
| customer_payment | Оплата покупателя за товар, работу или услугу |
| marketplace_revenue | Выплата продаж через маркетплейс по явному контексту |
| agency_revenue | Перечисление агентом выручки за оказанную услугу |
| operating_expense | Закупки, работы, услуги и прочие операционные затраты; текущая широкая категория также может включать ремонт/имущество |
| salary_advance | Явно указанный аванс зарплаты |
| salary_final | Явно указанный окончательный расчёт зарплаты |
| salary | Зарплата без достаточного уточнения аванса/окончательного расчёта |
| tax | Уплата налога, взноса или обязательного платежа; приписка о НДС в покупке не достаточна |
| rent | Аренда помещения/недвижимости |
| equipment_rent | Аренда оборудования |
| utilities | Коммунальные услуги |
| subscription | Регулярная подписка/сервис |
| bank_fee | Комиссия за банковскую операцию/обслуживание |
| overdraft_interest | Проценты за использование овердрафта |
| loan_payment | Погашение кредита/лизинга в нынешней широкой схеме |
| loan_receipt | Получение заёмных денег, кроме отдельно установленной помощи владельца |
| owner_financing | Заём/финансирование от явно указанного владельца/учредителя |
| owner_repayment | Возврат займа владельцу/учредителю |
| owner_capital | Взнос в уставный капитал |
| owner_withdrawal | Личный вывод предпринимателю/участнику, дивиденды |
| self_funding_unknown | Собственные средства без достаточного указания источника |
| own_transfer | Назначение явно указывает перевод между собственными счетами; это ещё не подтверждение второго подключённого счёта |
| own_transfer_candidate | Косвенный признак собственного перевода, например перенос остатка при закрытии; принадлежность не подтверждена |

| insurance_receipt | Страховое возмещение |
| grant_receipt | Субсидия/грант |
| enforcement_payment | Списание по исполнительному документу |
| unknown | Смысл не установлен, в том числе пустое назначение |

Список меток в конкретной выборке находится в её `instructions.md`; отсутствующая
в данных метка не добавляется в выборку искусственно. Схема широкая и не заменяет
бухгалтерский учёт. Неоднозначность — полезный результат разметки, не ошибка человека.

## Примеры альтернативных объяснений

- «Пополнение собственными средствами»: свой другой счёт, личные деньги владельца
  или заём? Без источника — `self_funding_unknown`, не выручка.
- «Перечисление по договору оферты»: маркетплейс, агент или обычный покупатель?
  Нужен контекст назначения/контрагента; без него — `unknown`.
- «Возврат по договору»: возврат ошибочной оплаты или гарантийного удержания?
  Различать только по явному тексту.
- «Без налога (НДС)»: это характеристика расчёта, не доказательство уплаты налога.
- Счёт с тем же ИНН: возможен собственный перевод, но совпадение само по себе
  не устанавливает конкретный счёт и пару движений. Сумму не удалять.

## Ограничения выборки

Отбор воспроизводим, стратифицирован по предсказанной категории/направлению,
с разнообразием компаний и исключением 141 прежнего целевого примера ассистента.
Это не случайная пропорциональная выборка всех операций. Простая доля совпадений
не является accuracy всего датасета; сначала нужны результаты по стратам,
анализ исключений и отдельный дизайн оценки популяции. Разметчикам не показывать
метки правил и прежние решения ассистента до сдачи независимых ответов.
