# ADR-032 — ручные дополнения после импорта

25.10.2026. Принято владельцем: «давай разрешим и исправим» после объяснения
ограничения одного источника фактов. Реализация локальная; приёмка и выкладка
этим решением не объявляются завершёнными.

После импорта счёт допускает ручные операции. У каждой записи сохраняется
собственное происхождение; внешняя привязка счёта не меняется. Прежнее правило
запрета manual после imported заменяется этим решением. Другой внешний namespace
и другая source company по-прежнему запрещены. Переход из изначально manual-only
истории к внешней привязке не входит в это исправление.

Обычные проверки write permission/CSRF, scope, CAS, idempotency и atomicity
сохраняются. Ручная операция повышает factual revision и делает старый прогноз
stale, не корректирует EOD и не переносит proof. CSV-профиль учитывает manual
вместе с imported facts, проверяет reconciliation и сохраняет provenance.

Точное совпадение ручного ввода с imported fact по дате, сумме, направлению,
ИНН, имени и назначению отклоняется как TRANSACTION_DUPLICATE_SUSPECTED.
Повторный импорт проверяется против manual facts; совпадение показывается как
SUSPECTED_CONTENT_DUPLICATE с предупреждением, что подтверждение сохранит обе
записи. Для одного движения пользователь исключает дублирующую строку из CSV.
Автоматической замены/удаления manual fact или изменения старого receipt нет.

Совпадающий по сумме manual EOD не заменяется statement EOD при следующем
импорте; его происхождение сохраняется. Конфликт суммы блокируется. Manifest
не выдаёт fixture proof для окна с ручными фактами или остатками; такой import
использует обычную оценку CSV, а старые snapshots/results остаются неизменными.

HTTP POST /companies/{company_id}/transactions подключается к существующему
Core CreateManualTransaction. Body строго проверяется, деньги/версии остаются
decimal strings, origin/CSRF и idempotency обязательны. UI разрешает кнопку
на imported account и поясняет предупреждения повторного импорта.

Миграция БД не требуется. Regression: manual после import, сохранение binding,
replay, imported duplicate, предупреждение/ack следующего импорта, одинаковый
manual EOD, новая оценка mixed history, stale старого результата, изоляция scope
и реальный HTTP adapter. Review — после завершённого блока; перед ним остановка
для переключения модели владельцем. Commit/push/merge/deploy отдельно.
